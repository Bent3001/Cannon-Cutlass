# CC-502 · Privaten Matchraum mit Einladung bereitstellen

| Status | Typ | Meilenstein |
| --- | --- | --- |
| Offen | Entwicklung | 5 · Online-PvP und Kampagne |

## Ziel

Zwei Personen brauchen eine Möglichkeit, dasselbe Online-Match zu eröffnen und auf ihre jeweilige Spielerrolle zurückzukehren.

## Umfang

Ergänze Raum anlegen, Einladungslink oder Code, Beitritt, Bereitschaft und Wiederverbindung nach den vereinbarten Identitätsregeln. Binde den Raum an den Online-Einstieg aus CC-716 an.

## Abnahmekriterien

- [ ] Zwei getrennte Browser-Sitzungen können denselben Raum als unterschiedliche Spieler betreten und einen eindeutigen Start auslösen.
- [ ] Der Gastgeber kann den Raum aus dem Hauptmenü öffnen. Der Gast kann einer Einladung direkt folgen.
- [ ] Eine dritte Sitzung kann die Rollen nicht übernehmen. Ungültige oder abgelaufene Einladungen zeigen eine verständliche Meldung.
- [ ] Eine berechtigte Sitzung kann nach einem Verbindungsabbruch den vereinbarten Wiedereinstieg nutzen.
