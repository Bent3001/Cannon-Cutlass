## Ziel

Das Echtzeitgefecht braucht zwei steuerbare Schiffe auf einer begrenzten Karte aus der Vogelperspektive.

## Umfang

Baue einen Rust-Simulationszustand mit Startposition, Fahrtrichtung, Geschwindigkeit, Beschleunigen, Abbremsen und Drehen. Führe Zeit und Eingaben in festen Schritten zu. Lege die ersten Richtwerte für kleine und große Schiffe als konfigurierbare Daten an.

## Abnahmekriterien

- [x] Ein Schiff kann mit denselben Eingaben in identischen Simulationsschritten dieselbe Position und Ausrichtung erreichen.
- [x] Beide Schiffe starten getrennt innerhalb der Arena. Beschleunigung, Höchstgeschwindigkeit und Arenagrenzen werden eingehalten.
- [x] Ein kleines Schiff kann mit den Prototypwerten schneller wenden als ein großes. Die aktive Spielansicht kann Position und Ausrichtung für beide Schiffe auslesen.

## Umsetzung

[`game_core::arena`](../../crates/game-core/src/arena.rs) verarbeitet die Eingaben beider Schiffe in Schritten von 1/60 Sekunde. Für jedes Schiff lässt sich ein Bewegungsprofil wählen. `Arena::ship(Player)` liefert Position, Ausrichtung und Tempo für die Ansicht. Startpositionen, Verhalten am Rand und die Prototypwerte für kleine und große Schiffe stehen in den [Spielregeln](../spielregeln.md#bewegung-im-arena-prototyp).

`BrowserArena` exportiert den Bewegungsprototyp aus demselben `assets/game.js`, das die Spielseite lädt. Die Instanz startet mit dem kleinen und dem großen Prototypprofil. `step` erhält je eine Gas- und Lenkeingabe pro Schiff und simuliert genau einen Schritt. `view` liefert `x`, `y`, `heading` und `speed` für beide Schiffe in Spielerreihenfolge sowie Kartengröße und Schrittfrequenz. [WASM-Adapter](../../crates/game-wasm/src/arena.rs)

### Manuell nachprüfen

Über `just start` oder den per HTTP bereitgestellten Export die Spielseite öffnen und warten, bis die Aufstellung angezeigt wird. In der Browserkonsole ausführen:

```js
const { BrowserArena, ArenaThrottle, ArenaSteering } = await import("./assets/game.js");
const arena = new BrowserArena();
const start = JSON.parse(arena.view());
for (let i = 0; i < start.steps_per_second; i++) {
    arena.step(ArenaThrottle.Accelerate, ArenaSteering.Right,
        ArenaThrottle.Accelerate, ArenaSteering.Right);
}
const end = JSON.parse(arena.view());
console.table(end.ships.map((ship, i) => ({
    ...ship, turn: ship.heading - start.ships[i].heading,
})));
arena.free();
```

Beide Zeilen zeigen neue Koordinaten und positive Geschwindigkeit. Die Drehwinkel betragen etwa 2,8 und 1,4 rad.
